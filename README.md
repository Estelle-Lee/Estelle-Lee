# 이보경 (Bokyung Estelle Lee)
**백엔드 엔지니어**

복잡한 비즈니스 로직을 안정적인 시스템으로 구현하고, 데이터 기반으로 성능 병목을 해결하는 백엔드 엔지니어입니다. 차세대 학습 플랫폼(LXP) 구축, 이기종 DBMS 마이그레이션, FFMPEG 미디어 프로세싱, 시스템 자동화 등 기술 난도가 높은 영역을 실무로 다뤄왔습니다.

- **성능 최적화** — APM 기반 병목 진단으로 쿼리 수행 시간 6.0s → 0.9s (약 85% 단축), 동시접속 2,000명 부하율 0% 달성
- **이기종 마이그레이션** — 한양대 클라우드 전환사업에서 Oracle → Tibero 무중단 이관 및 쿼리 재설계
- **시스템 자동화 · 데이터 파이프라인** — 카카오 알림톡 자동화 엔진, FFMPEG 미디어 처리, xAPI/LRS 학습데이터 수집 환경 구축
- 학부(이공계 B.Sc)에서 객체지향·Java·C/C++·자료구조 전공, 영국 글래스고 대학 소프트웨어 개발 석사 Distinction(최우수) 수료
